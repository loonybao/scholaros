Job description
Project title:
High power broadband fiber-based structured light with machine learning tuneable spatio-temporal characteristics
Project tasks and objectives
:  This doctoral project will explore how AI can control complex light inside multimode optical fibers. You will develop high-power broadband structured-light sources and use machine learning to tune their spatial, spectral and temporal properties on demand. The work combines nonlinear fiber optics, structured light, ultrafast photonics and AI, with the goal of turning complex multimode dynamics into a programmable light source rather than an uncontrolled effect.
Expected results
: The project will deliver new methods for AI-programmable all-fiber structured-light generation, enabling dynamically tunable beam shape, spectrum and temporal behavior at practical power levels. Potential applications include imaging, sensing, laser processing and industrial inspection.
