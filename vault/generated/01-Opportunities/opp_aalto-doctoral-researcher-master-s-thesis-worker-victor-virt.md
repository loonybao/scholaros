Description of the project
Knowledge of the torque and torsional response of a maritime powertrain is important for emission-compliant control. Torque and torsional response are normally measured using strain gauges, dedicated torque sensors, or other instrumentation installed on the drivetrain. Torsional response can also be calculated if the external torsional forces acting on the powertrain are known, but measurements of this external forcing are rare in maritime powertrains. Instrumenting large maritime powertrains is also costly, and there is often not enough measured information available to fully determine the torsional response using conventional methods alone.
Unknown external forces and torsional response can instead be estimated using methods such as convex optimization or Kalman filtering. These torque estimation methods allow much more freedom in sensor placement and reduce the number of sensors needed to characterize the full torsional response of the powertrain.
This project aims to develop a torque estimation procedure that determines the unknown input torque and full torsional response using only encoder (speed, position) measurements together with selected available measurements from the driving internal combustion engine (e.g. cylinder pressure) or the driven electric generator (e.g. electromagnetic torque) — removing the need for an expensive, dedicated torque transducer.
Two complementary approaches will be explored. The first is convex optimization-based torque estimation, which allows constraints to be incorporated flexibly, both to keep estimated quantities physically consistent and to enforce desired structure in the results. The second is physics-informed learning, which combines available historical data with known system dynamics as a regulariser for data-driven learning — enabling nonlinear system dynamics to be learned indirectly with less training data than traditional data-driven approaches, for example to estimate the external torsional excitation from the propeller.
To ultimately remove the need for a torque flange, the estimation method must be integrated into the embedded engine control system. The work will make use of industry-standard tools such as Matlab Simulink to connect with existing control systems and support SIL/MIL simulation, and the resulting algorithm must run efficiently within the CPU constraints of an embedded system.
The project is carried out in collaboration with Wärtsilä, which provides powertrain data, operational torsional-dynamics measurements for model verification, and access to a physical maritime powertrain for validating the developed torque estimation procedure. You will be employed by the University, but your work will be conducted physically both at Aalto University campus and Wärtsilä Vaasa STH laboratory, to provide best-possible methodological support for your doctoral dissertation project.
