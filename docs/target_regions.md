# Target regions — tiered

Basis for the tiering: user preference (Nordic first, don't drop the rest) ×
HCI / human-centred XR research strength × funding + visa openness for a non-EU
(Malaysian) applicant. Salaried, English-taught, internationally-open PhD models
(Nordic / Netherlands / Switzerland) rank highest. Drives: EURAXESS country +
research-field facets, dedicated-collector priority, and `constraints.yaml`
`preferred_countries` (strategic-value weighting only — never the gate).

## Tier 1 — core targets (Nordic + Netherlands)
| Country | Strong HCI/XR groups (beyond ones already collected) | Notes |
|---|---|---|
| Finland | Aalto ✓, Tampere/TAUCHI ✓, Oulu (ubicomp) | salaried PhD, English |
| Sweden | KTH, Chalmers, Umeå (design+HCI), Lund, Linköping, Uppsala | salaried, very open to internationals |
| Denmark | Aarhus (world-class HCI / participatory design), ITU Copenhagen (HCI/games), KU, DTU, Aalborg | salaried, English, top HCI |
| Norway | NTNU Trondheim, Oslo | salaried, English |
| Netherlands | TU Delft ✓ (MXR Lab), TU Eindhoven (industrial design), Twente, Utrecht | salaried, English |

## Tier 3 — opportunistic (monitor via EURAXESS; surface only strong/relevant)
France (Inria HCI/VR, Sorbonne ISIR, Grenoble), Austria (Salzburg HCI, TU Wien,
JKU Linz), and other Western/Central EU. Funding/language varies — rely on
EURAXESS + analysis to pick.

## Tier 4 — out of scope
Non-Europe (US / Australia / Hong Kong / Macau / Singapore …) — excluded by the
Europe geography gate.

## Dedicated-collector priority (if built beyond the current 3)
Tier-1 gaps first: **KTH, Chalmers, Aarhus, ITU Copenhagen, TU Eindhoven**.
Everything else is covered breadth-first by EURAXESS (with the facets above),
auto-analysed once a live LLM API is configured.
